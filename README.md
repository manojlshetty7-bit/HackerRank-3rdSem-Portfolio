## Problems Solved

The following five HackerRank problems were solved as part of this activity:

1. **Diagonal Difference**
   - Topic: 2D Arrays / Matrices
   - Calculates the absolute difference between the sums of the two diagonals of a square matrix.

2. **Dynamic Array**
   - Topic: Data Structures / Vectors
   - Uses dynamic sequences and XOR-based indexing to process queries.

3. **Time Conversion**
   - Topic: Strings / Logic
   - Converts a 12-hour AM/PM time format into 24-hour format.

4. **Compare the Triplets**
   - Topic: Arrays / Comparison
   - Compares the scores of Alice and Bob and calculates their respective points.

5. **Sparse Arrays**
   - Topic: Strings / Hash Maps
   - Counts how many times each query string occurs in the given string list.
